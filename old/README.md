# Old tools

This list describes old tools that I previously used in my environment, that have been removed or replaced with other tools.

## Alfred

Alfred is a productivity app and "Spotlight" alternative for MacOS. It can be installed using [this link](https://www.alfredapp.com/). For configuration, set the `cmd+ç` as the hotkey for the Alfred search bar.

It was replaced by Raycast.

## Rectangle

Rectangle is a simple window manager. It can be installed using [this link](https://rectangleapp.com/).

It was replaced by Aerospace.

## ITerm2

iTerm2 is a terminal emulator. It was replaced by Ghostty.

## Oh My Zsh

It was replaced by Ghostty + Starship.

## zsh

It contains the `.zshrc` file that was used for ITerm2 and Oh My Zsh.
