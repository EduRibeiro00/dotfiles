# SketchyBar

The `/sketchybar` folder contains all the configuration files needed to setup SketchyBar in a new computer. It contains the following files and folders:

- `/plugins` - folder containing the scripts for each widget in the bar (e.g. battery, volume, etc)
- `colors.sh` - simple file containing some contants with color values.
- `sketchybarrc` - the main configuration file for SketchyBar.
