# Other things to install/configure

# Homebrew

Homebrew is a package manager for MacOS, that will allow the installation of other tools stated here. It can be installed using [this link](https://brew.sh/).

## Rectangle

Rectangle is a simple window manager. It can be installed using [this link](https://rectangleapp.com/).

## Alfred

Alfred is a productivity app and "Spotlight" alternative for MacOS. It can be installed using [this link](https://www.alfredapp.com/). For configuration, set the `cmd+l` as the hotkey for the Alfred search bar.

## fzf

fzf is a command-line fuzzy finder, that is used as the basis for some commands defined in the `.zshrc` file. It can be installed by running the command `brew install fzf`.

## flux

flux is an app that changes the color and brightness of the computer display based on what time it is and the brightness of the room. It can be installed using [this link](https://justgetflux.com/).

## MacOS Settings

Some MacOS settings that should be changed:
- `Appearance`
  - change to dark mode
- `Desktop & Dock`
  - toggle "Automatically hide and show the Dock"
  - change default web browser to Firefox
- `Keyboard`
  - change "Key repeat rate" to Fast, and "Delay until repeat" to Short
  - change keyboard input source to Portuguese
- `Trackpad`
  - toggle "Tap to click"
